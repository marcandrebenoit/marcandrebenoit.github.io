# Uptime Kuma Quick Start

Uptime Kuma is a beautiful monitoring tool that alerts you if your websites or services go down.

---

### Setup
1. Create a folder: `C:\Docker\uptime-kuma`
2. Create `docker-compose.yml` inside and paste this:

```yaml
services:
  uptime-kuma:
    image: louislam/uptime-kuma:1
    container_name: uptime-kuma
    volumes:
      - ./data:/app/data
    ports:
      - 3001:3001
    restart: always
```

### Run It
1. Open PowerShell.
2. `cd C:\Docker\uptime-kuma`
3. `docker compose up -d`

Access at: http://localhost:3001
