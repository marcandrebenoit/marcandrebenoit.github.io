# # Getting Started with Docker Compose: A Simple Guide

Hey! This guide will help you set up a powerful "toolbox" on your computer using **Docker Compose**.

---

### 1. Install Docker (The Clean Way)
We use Windows' built-in package manager (**winget**) to install the engine.

1.  Right-click your **Start Button** and select **Terminal (Admin** or **PowerShell (Admin**.
2.  Paste this command and hit Enter:
    ```powershell
    winget install -e --id Docker.DockerDesktop
    ```
3.  **Restart your computer** after the installation finishes.

---

### 2. Organizing Your Projects
To keep things tidy, we will give every "app" its own folder.

1.  Create a main folder called `C:\Docker`.
2.  Inside that, create a folder for our first project: `C:\Docker\stirling-pdf`.

---

### 3. Creating Your First "Compose" File
1.  Open **Notepad** and paste the following recipe for **Stirling-PDF** (a local tool to edit PDFs):

```yaml
services:
  stirling-pdf:
    image: stirlingtools/stirling-pdf:latest
    ports:
      - '8080:8080'
    volumes:
      - ./trainingData:/usr/share/tessdata
      - ./extraConfigs:/configs
    environment:
      - DOCKER_ENABLE_SECURITY=false
```
2.  Save this file as `docker-compose.yml` inside `C:\Docker\stirling-pdf`.

---

### 4. Running Your App
1.  Open **PowerShell**.
2.  Move into your project folder by typing: `cd C:\Docker\stirling-pdf`
3.  **Pull the app:** `docker compose pull`
4.  **Start the app:** `docker compose up -d`

Open your browser to: http://localhost:8080

---

### 5. Essential Commands
Always run these inside the project folder.

| Command | What it does |
| :--- | :--- |
| `up -d` | Start the app in background. |
| `down` | Stop and remove the app. |
| `restart` | Quickly reboot the app. |
| `pull` | Update to the latest version. |
| `ps` | Shows if the app is running. |
| `logs -f` | Shows internal errors. |

---

### 6. Need System Info?
Use these in PowerShell:
*  `docker stats` : Live CPU and RAM qsage.
*  `Get-ComputerInfo` : Full Windows system details.
